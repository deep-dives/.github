# holtwood-forks/.github

Holtwood Forks 的组织级配置仓库。组织主页显示在 [`profile/README.md`](profile/README.md)。

本仓库只放组织主页与默认社区健康文件，不含业务代码。

## 内容

| 路径 | 作用 |
|------|------|
| `profile/README.md` | 组织主页 |
| `CONTRIBUTING.md` | 贡献指南（全组织默认） |
| `SECURITY.md` | 安全策略（全组织默认） |

## 维护

组织内新增 fork 时，同步更新 `profile/README.md` 的分组表。
